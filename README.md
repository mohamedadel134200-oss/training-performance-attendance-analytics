# Training Performance & Attendance Analytics

## Project Overview
This end-to-end analytics project combines SQL Server and Power BI to analyze trainee performance, attendance, grades, courses, and instructor performance.

The project demonstrates how raw training data can be transformed into structured analytical insights using advanced SQL techniques and interactive Power BI dashboards.

## Key Objectives
- Analyze trainee academic performance
- Monitor attendance behavior
- Evaluate pass and fail rates
- Compare trainee scores across courses
- Assess instructor performance
- Identify performance patterns and training trends
- Support data-driven training decisions

## Key KPIs
- Total Trainees
- Attendance Rate
- Fail Rate
- Average Final Score
- Instructor Average Performance
- Trainee Performance Levels
- Course Performance

- Performance segmentation

## Project Workflow

1. Prepare and load the training database in SQL Server.
2. Analyze the data using SQL queries.
3. Build reusable analytical views and queries.
4. Connect the prepared data to Power BI.
5. Develop KPIs and interactive visualizations.
6. Transform the results into actionable training insights.
